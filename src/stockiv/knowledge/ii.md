2.  **TÓM TẮT**

- **3 báo cáo tài chính**

<!-- -->

- **Cân đối kế toán:** báo cáo tài sản (công cụ sản xuất) và nguồn vốn
  của DN tại [1 thời điểm]{.underline}

- **Kết quả kinh doanh:** báo cáo doanh thu, lợi nhuận của DN trong [1
  giai đoạn]{.underline}

- **Dòng tiền:** Trạng thái tiền từ 3 hoạt động: kinh doanh, đầu tư và
  tài chính.

![](media/image2.png){width="6.267716535433071in"
height="2.8635520559930008in"}

- **Nguyên tắc double-entry:** Bất kỳ 1 giao dịch nào trong kinh doanh
  đều được ghi nhận trên sổ sách theo nguyên tắc double-entry (đối ứng
  kép). Đó là việc ghi nhận cả "được" và "mất" của giao dịch đó. Giống
  như "hình" và "bóng" của con người, mọi giao dịch đều để lại "dấu
  vết". Đó là lý do BCTC là công cụ tốt nhất để đánh giá doanh nghiệp.

- **Các loại báo cáo của 1 doanh nghiệp đại chúng:**

+--------------+-----------------------------------------------------+
| Theo thời    | - Bản cáo bạch : tại thời điểm IPO                  |
| gian         |                                                     |
|              | - Báo cáo thường niên: kết thúc năm                 |
|              |                                                     |
|              | - Báo cáo quý, 6 tháng, 9 tháng                     |
+--------------+-----------------------------------------------------+
| Cấu trúc báo | - Định tính                                         |
| cáo thường   |                                                     |
| niên         |   - Mô hình kinh doanh & ngành                      |
|              |                                                     |
|              |   - Đánh giá tình hình hoạt động năm vừa rồi        |
|              |                                                     |
|              |   - Định hướng chiến lược năm tới                   |
|              |                                                     |
|              | - Định lượng (3 báo cáo)                            |
|              |                                                     |
|              | - Thuyết minh báo cáo (giải thích số liệu)          |
+--------------+-----------------------------------------------------+
| Theo cấu     | - Báo cáo riêng lẻ: báo cáo của công ty mẹ          |
| trúc DN      |                                                     |
|              | - Báo cáo hợp nhất: hợp nhất toàn tập đoàn          |
+==============+=====================================================+

- **Tóm tắt hướng dẫn đọc báo cáo tài chính:**
