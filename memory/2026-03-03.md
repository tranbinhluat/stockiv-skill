**Implementation Notes:**
- CrewAI 1.9.3 uses event-based system, not `CrewAICallbacks`
- Events registered via `crewai_event_bus.on(EventType)(handler)`
- Callbacks use singleton pattern to avoid duplicate handlers

**Log Viewer Usage:**
```bash
uv run python tools/view_logs.py --list              # List all logs
uv run python tools/view_logs.py --tail 10          # Last 10 events
uv run python tools/view_logs.py --filter task_end  # Filter by event
```

- `config/agents.yaml` - Agent role/goal/backstory
- `config/tasks.yaml` - Task description/expected_output

**Usage Pattern:**
```python

```
