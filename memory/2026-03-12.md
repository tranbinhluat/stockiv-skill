## Session 2: Synthesizer ↔ Director Review Loop Architecture

### Research Findings
1. **CrewAI `output_file` + `output_pydantic`** = writes raw JSON (not markdown). `markdown: true` only adds a prompt instruction — does NOT change file output.
2. **CrewAI `crew.replay(task_id, inputs)`** = replays from a specific task with new inputs while preserving prior task outputs. Useful for feedback loops — only re-runs the synthesis task on retry.

### Changes Made
1. **Director Crew (`director.py`)**:
   - Removed inline `ValidationDecision` (2 fields)
   - Now uses `DirectorDecision` from `models.py` (~15 structured fields)
   - Review file written via `.to_markdown()` — rich, parseable review with ✅/❌ checks, anomalies, failure lists, next steps

2. **Report Loop (`report_loop.py`)**:
   - **Replay-based retry**: On Director rejection, uses `crew.replay()` to re-run ONLY `compile_evaluation_report` (preserves data extraction from tasks [0] and [1])
   - Split `_run_synthesizer()` → `_run_synthesizer_full_kickoff()` + `_run_synthesizer_replay()` + `_run_synthesizer_mock()`
   - First pass: full `crew.kickoff()`, stores crew instance + compile task ID
   - Retries: `crew.replay()` with new feedback inputs, fallback to full kickoff if replay fails
   - Updated Director result extraction for `DirectorDecision` fields
   - Mock reviews match `to_markdown()` format

3. **Minor fix**: Added `advanced_llm` to `__all__` in `agents/__init__.py`

### Design Decisions
- **Option B for Director output**: Keep `output_pydantic=DirectorDecision` + manual `.to_markdown()` write. Gives both typed routing AND human-readable review files.
- **Replay over full re-kickoff**: Saves ~2/3 tokens per retry round. Prior data stays fixed; only synthesis changes.
- **Fallback safety**: If replay fails (e.g., no stored outputs), falls back to full kickoff automatically.
