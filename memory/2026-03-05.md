## Morning - Data Expansion & Caching (Completed)

**Commit:** `feat(collector): expand data extraction for GCCP framework`

**Objective:** Extract missing company overview metrics (size, capital, outstanding shares) and the 46-metric deep ratio dump from vnstock to support the quantitative pipeline. Additionally, ensure we don't spam the API whenever the Collector Crew is invoked multiple times a day.

**Key Achievements:**
1.  **Added `fetch_company_overview` Tool:** Extracts deep company descriptors for the "Top 100 Size" defensive criteria to `company_overview` SQLite table. (Cached inherently).
2.  **Added `fetch_ratio_summary` Tool (VCI):** The absolute game-changer. Returns 46 dynamically calculated metrics including `PE`, `PB`, `PS`, `EV/EBITDA`, `Dividend Yield`, `ROA`, `ROE`, etc. 
3.  **Dynamic Date Caching:** Realized that tracking `ratio_summary` by `year_report` misses the fact that `PE` and `PB` fluctuate daily with the stock price. Updated the SQLite schema to track this on a `(ticker, date)` compound primary key so agents always get the latest price ratios without duplicating historic data.
4.  **SQL Query-First Cache Check:** Modified all 4 vnstock tools to execute a `SELECT MAX(...)` statement before firing a `requests.get()`. If the data exists locally (either for that quarter or that day), the tools immediately return a cache-hit instead of hitting an API block.
5.  **Agent Integration:** Integrated the two new robust tools into the `fetch_daily_market_data_task` so the `MarketDataFetcher` runs them dynamically.
