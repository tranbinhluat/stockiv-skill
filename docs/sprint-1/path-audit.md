None are under `.agents/`.  
Restructuring `.agents/skills/` → `.agents/plugins/stockiv-plugin/` has zero impact on any data file paths.**

## Path Discrepancy Found (Sprint 2 Review Item)

| Location | Path Used |
|---|---|
| `plan.md` skill-routing spec + knowledge-map spec | `data/processed/sentiment/ticker/{TICKER}_sentiment.md` |
| Actual `analyze-sentiment/SKILL.md` output | `data/processed/sentiment/ticker/{TICKER}/{YEAR}_W{WW}_sentiment.md` |
| Actual `analyze-fundamentals/SKILL.md` input | `data/processed/sentiment/ticker/{TICKER}/{YEAR}_W{WW}_sentiment.md` |
| Actual `draft-report/SKILL.md` input | `data/processed/sentiment/ticker/{TICKER}/{YEAR}_W{WW}_sentiment.md` |

**The plan.md spec uses a simplified path (no year/week versioning). The actual SKILL.md files use the full versioned subdirectory path.**  
`skill-routing.md` and `knowledge-map.md` were created using the plan.md spec paths (as instructed). Reconciliation is a Sprint 2 review item — do not edit SKILL.md content in Sprint 1.
